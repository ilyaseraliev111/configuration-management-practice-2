Загрузки пакетов, сетевых обращений и построения графа пока нет.

## Запуск и проверка

Откройте в PyCharm всю папку, содержащую `src`, `README.md` и `run.bat`.
Откройте Terminal (Alt+F12). Команды выполняются в PowerShell; REPL здесь нет.
Каждый запуск заканчивается сам, результат ошибки выводится в stderr.

```powershell
python -m src.main --package busybox --version 1.0-r0 --repository https://example.org/apk
python examples/demo_stage1.py
python -m unittest discover -s tests -v
```

Можно использовать `run.bat` с теми же аргументами. На Linux/macOS:
`sh run.sh --package busybox --version 1.0-r0 --repository https://example.org/apk`.
Программа интерпретируется: отдельная сборка и `pip install` не требуются.

## Параметры

| Опция | Назначение |
| --- | --- |
| `--package NAME` | Обязательное имя пакета |
| `--repository SOURCE` | Обязательный HTTP(S) URL или путь при `--test-repo` |
| `--test-repo` | Логический флаг тестового репозитория, по умолчанию выключен |
| `--version VERSION` | Обязательная точная версия корневого пакета в синтаксисе APK |
| `--ascii` | Флаг будущего ASCII-дерева; по умолчанию выключен |
| `--max-depth N` | Неотрицательная глубина, по умолчанию 3; корень — 0 |
| `-h`, `--help` | Справка |

Флаги не принимают значения: используйте `--ascii`, а не `--ascii true`.
Для тестового режима требуется существующий файл и имя из букв A–Z.
Пути с пробелами заключайте в двойные кавычки.
Проверяется синтаксис URL; доступность сети будет проверяться на этапе 2.
Версия `latest` недопустима: нужно конкретное значение, например `1.0-r0`.
Коды: `0` — успех, `2` — ошибка опций. В PowerShell код виден через `$LASTEXITCODE`.
Демонстрационный скрипт проверяет, что намеренные ошибки возвращают `2`.

## Функции и файлы

- `src/config.py`: `Config`, `build_parser`, `depth_value`, `parse_config`, `print_config`.
- `src/validation.py`: `validate_name`, `validate_version`, `validate_url`, `validate_source`.
- `src/main.py`: `main`, запуск прототипа.
- `examples/common.py`: `run_case`, запуск дочернего Python; `utf8_environment`, кодировка.
- `examples/demo_stage1.py`: `arguments`, исходные опции; `main`, автоматическая демонстрация.
- `tests/test_config.py`: обязательные опции, значения, пути, флаги, ошибки и вывод.

`stage1-config` сохраняет этот этап отдельным коммитом.
